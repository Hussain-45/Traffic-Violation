# Report Generation Architecture

The **Report Generation Subsystem** compiles aggregated metrics, trend figures, and audit logs from the database layer and `AnalyticsService` into exportable documents.

---

## 1. Directory Structure

```
backend/app/
├── models/
│   └── report_model.py          # SQLAlchemy ORM definition for 'reports'
├── schemas/
│   └── report_schema.py         # Request filter schemas and response encoders
├── repositories/
│   └── report_repository.py     # Database CRUD operations for report logs
├── services/
│   ├── report_service.py        # Orchestrates analytics data and generates files
│   └── report_template_service.py # Standardizes cover pages, KPIs, and footers
├── controllers/
│   └── report_controller.py     # Mediate requests between routers and service
└── api/
    └── v1/
        └── reports.py           # REST endpoints
```

---

## 2. API Endpoints

All endpoints are registered under `/api/v1/reports`:

| Method | Endpoint | Description |
|--------|----------|-------------|
| **GET** | `/api/v1/reports` | Lists all generated reports in history. |
| **POST** | `/api/v1/reports/generate` | Compiles a new report (PDF, CSV, Excel, JSON). |
| **GET** | `/api/v1/reports/download/{id}` | Streams the physical report file to the client. |
| **GET** | `/api/v1/reports/history` | Audits the report logs database. |
| **GET** | `/api/v1/reports/templates` | Lists supported templates and parameters. |
| **GET** | `/api/v1/reports/export` | Downloads a ZIP archive of all completed reports. |
| **GET** | `/api/v1/reports/health` | Diagnostics check on writing access and directory health. |
| **DELETE** | `/api/v1/reports/delete/{id}` | Removes a report file and its database record. |

---

## 3. Template Renderers

Reports follow standard layouts:
- **PDF Cover Page**: Standardized title, date ranges, and confidentiality notice.
- **KPI Metrics**: Displays active cameras, total scans, fine sums, and AI confidence scores.
- **Distributions Grid**: Maps vehicle classes alongside violation categories.
- **Footer**: Unified labeling: `Generated by Traffic Violation AI | Page X | Confidential`.
